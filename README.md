# Dem tom nho

Ung dung GUI dem tom bang YOLO. Ban chay duoc voi file `đem_tom_nho.py` va model `nano.pt` dat cung thu muc.

## File can co

- `đem_tom_nho.py`
- `nano.pt`
- `requirements.txt`

## Cai dat

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Chay ung dung

```powershell
python "đem_tom_nho.py"
```
